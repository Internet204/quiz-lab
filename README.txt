LOCAL QUIZ LAB

Windows: double-click start.cmd. Keep the console open while using the page.
macOS/Linux: python3 server.py --open
Open http://127.0.0.1:8766
Requires Python 3. No packages or API keys are required.

20 practice questions: single choice, multiple choice, numeric/text answers,
dropdowns and matching. Switch between one question and all questions.
Answers and flags persist in this browser. Finish attempt shows the score;
there are no yellow correct-answer panels. Practice settings can block paste
or show an animated mock camera tile. It does not access your camera.
Start a new attempt clears answers. The timer does not auto-submit.
This is a local practice fixture, not an official university page.
